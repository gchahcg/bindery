### Added
- **Duplicate-title review for an author's catalogue** (#1970): a new read-only report, opened from the author page's **More → Review duplicates…**, groups books whose titles look like the same work — a punctuation or diacritic variant, a leading article, an edition marker, or a subtitle folded into the other title — and explains which rule matched. Nothing changes automatically; excluding a row uses the existing exclude action. The "title contained in the other" rule is skipped when two books are known, different entries in the same series, so a long series-opener title no longer flags its own sequels (e.g. "Foundation" against "Foundation and Empire").
